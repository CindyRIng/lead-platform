## 2. 各源口径与质量

### 2.1 Mic（5,008）

- **口径**：`province=Hebei` 省关键词 + 11 个地级市关键词的全量并集（client `enumerate-province.mjs`）。
- **质量**：高。省份/城市/会员/认证来自平台字段；5,008 家详情已全部拉取成功（5008/5008）。
- **注意**：单省关键词仅 1,101 家（只匹配公司资料提及“河北”的），**必须按城市关键词并集**才是 5,008。

### 2.2 Ali（2,961）

- **口径**：129 个地理种子（3 省 + 11 市 + 115 县，名称启发式 + 详情核验）→ 1,799；再加行业×城市矩阵两轮（20 + 12 行业 × 11 市 + 省行业词，strict 模式）→ 净增 +663 / +328 → **2,961**。
- **质量**：中高。
  - 详情确认/strict 确认：约 **1,631 家（55%）**；
  - 名称启发式：**1,330 家（45%）**（英文名含 Hebei/11 市/115 县拼音 token；抽样 60/60 准确，**建议上线前逐家详情核验**，约 15–25 分钟）。
- **不可得**：平台无省级全量目录、无官方“河北供应商总数”；2,961 是“可发现量”，两轮扩展增量 +663→+328 递减，估算上限 **3.1–3.3k**。
- **风险**：英文名与注册名不一致、同名/缩写误判；跨平台去重（Ali∩Mic）依赖英文名匹配，可能漏配。

### 2.3 Boss / 智联（1,188 / 1,261 → 2,375）

- **口径**：11 市 × 10 关键词（外贸、外贸业务员、外贸经理、外贸单证员、国际贸易、跨境电商、外贸跟单、外贸专员、海外销售、国际业务）× 搜索结果**第 1 页**，按公司去重。
- **质量**：中。岗位搜索反推公司，公司名常为简称（如“示例丁”），只覆盖“正在招聘”的公司；深翻页会显著增加（预计 +30–100%）但需再跑 1.5–2h/源。
- **去重**：中文名归一化（去后缀、去河北/城市前缀，含简称-全称包含匹配，城市一致优先）；Boss∩智联 = 74，可能漏配（简称/同名）。
- **非河北过滤**：Boss/智联均按 cityCode 检索河北 11 市；公司 cityName 归属河北。

## 3. 去重方法细节

### 3.1 中文源（Boss/智联）

1. 名称归一化：去括号内容、空格/标点；去后缀（股份有限公司/有限责任公司/有限公司/集团/分公司/公司）；去开头省份/城市词（河北/石家庄/…）。
2. 匹配：归一化全名相等 → 同一；核心名相等且长度≥4 → 同一；一个包含另一个（短名≥4 字）且城市一致/未知 → 同一。
3. 城市字段：Boss/智联均返回中文城市名，直接比较。

### 3.2 英文源（Ali/Mic）

1. 归一化：大写、`&`→AND、去标点、去停用词（CO/LTD/GROUP/CORP/…）与省份/城市 token。
2. 匹配：精确同名 → 同一；非地名 token 交集 ≥2 且 Jaccard ≥0.7 → 同一；单 token 长≥6 且城市一致（较保守）→ 同一。
3. 局限：同一公司英文写法差异（如 `Imp&Exp` vs `Import & Export`）会漏配；459 是下限。

### 3.3 跨语言（中文源 ↔ 英文源）

- 方法：随机抽样 160 家英文源（Ali/Mic 各 80）→ 探迹 `search/name` 用英文抬头匹配中文主体 → 检查该中文名是否出现在中文源名单（归一化包含匹配）。
- 结果：6/160 = **3.75%**，95% CI 0.8%–6.7%；外推英文源 7,990 家 → 重叠 ≈299（区间 64–533）。
- 局限：概率抽样（n=160 偏小）、探迹匹配本身可能失败（英文名/简称）、名单匹配可能漏配。**该数是估计值，不是精确值**。

## 8. v2：leads / companies 分层口径（2026-11-17）

- **lead**：上游平台的一条原始企业记录（Boss/智联/Ali/Mic），名称可能为简称/英文/不准确；存在 `leads` 表，`company_id` 指向内部草稿。
- **company**：**仅探迹确认主体**（`tanji_company_id` 非空、`verified=1`）；对外公司列表、覆盖率、平台档案、海关、解锁只认 company。
- **lead_company_matches**：lead ↔ company 多对多（一个英文抬头可匹配多个 company），带 method/confidence/rank/is_primary。
- 统计口径：`/v1/companies` 与 `/v1/stats?kind=coverage` 只含 verified company；`/v1/leads` 与 `/v1/stats` 的 leads/drafts 字段单独展示；不再把未核实线索算入公司数。
- 迁移后当前值：verified company **1,327**、leads **8,050**、内部草稿 **5,876**。
