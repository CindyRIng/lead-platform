## 2. 通用限频与缓存（来自各 client 的 `.env.example` / 实测）

| 来源 | 速率 | 页间隔 / 并发 | 单次页数上限 | 缓存 TTL |
|---|---|---|---|---|
| boss | `BOSS_RATE_PER_MIN=12` | 页间 2500ms | `pages≤5`（列表页可继续按 queryId 续翻） | query 24h、公司 7d |
| zhilian | `ZHILIAN_RATE_PER_MIN=15` | 页间 2500ms + jitter；并发 1 | `pages≤5` | query 24h、公司 7d |
| ali | 页间隔 10s | 详情并发 2 | `pages` 默认 5、硬上限 20；`maxEnrich≤300` | 搜索 2h、详情 7d |
| mic | 默认 1 req/2s（可配） | 串行 | 上游原页 20 条/页（client 分页） | 有缓存（`/api/cache/stats`） |
| tanji | `TANJI_RATE_PER_MIN=20` | 解锁走 priority；批量读队列 | `maxPages≤50`（单次任务） | 列表 24h、详情 7d |

> LeadPlatform 不重复实现并发控制，只保证「每个来源内部串行 + 请求间隔 ≥ client 的限频」，并在上游报 429/风控时冷却。

## 3. 各来源对接明细

### 3.1 boss-client（招聘线索）

**检索**

```http
POST /v1/search/jobs
Authorization: Bearer $BOSS_API_TOKEN
{"keyword":"外贸业务员","cityCode":"101090100","page":1,"pageSize":100,"pages":5}
```

- 返回 `queryId` + 首屏岗位；后续 `GET /v1/jobs?queryId=...&page=N` 翻页。
- `GET /v1/companies?queryId=...` 把岗位结果**按公司去重**（含 `companyId/name/industry/scale/cityName/address/jobCount/matchedJobs/firstSeenAt/lastSeenAt`）→ LeadPlatform 以此为线索来源。
- 深度策略：对每个（城市 × 关键词）检索到「上游无更多页」或「达到配置上限」为止；客户端 `pages` 上限 5 只影响单次调用，LeadPlatform 可用 `GET /v1/jobs` 继续翻页。

**详情（拿 USCC 提示）**

```http
GET /v1/companies/{companyId}
```

- `.business.companyName/legalRepresentative/foundedAt/registeredCapital/registeredAddress/businessScope/uscc`
- **注意**：`business.usccSource="boss_company_page_text"`、`textDerived=true` —— 来自雇主页文本推导，可能缺失/错误；仅作为探迹精确搜索的提示，最终以探迹为准。
- `.recruiters`（招聘者姓名/职位）可作为来源证据，不作为联系人入库。

**登录态**：`GET /v1/status` → `loggedIn`、`session.expiresAt`、`risk.code37Count`；Boss 会话约 5 天（本次实测 2026-11-21 到期）。需要人工扫码/短信，LeadPlatform 不登录。

**区域字典**：`GET /v1/cities?refresh=true` → 374 城（内置仅 50 个常用城市）；刷新结果只有 `cityCode/cityName`（无 province），需按名称匹配到内置规范城市表。

### 3.2 zhilian-client（招聘线索）

**检索**

```http
POST /v1/search/jobs
{"keyword":"外贸","cityCode":"565","page":1,"pages":5}
```

- 后续 `GET /v1/jobs?queryId=...`；`GET /v1/companies?queryId=...` 按公司去重。
- 深度策略同 Boss；`pages≤5`。

**详情**

```http
GET /v1/companies/{companyNumber}
```

- `.business.registeredName/uscc/legalPerson/registeredCapital/businessStatus/createDate/registeredOrg/location/registeredAddress/businessScope/creditLevel/industry`
- USCC 来自 `epCertNo`（文本推导），同样只作提示。

**登录态**：`GET /v1/status` → `loggedIn`、`mode`、`verification.pending`（EdgeOne/极验/NC）、`risk.blockCount`；会话约 1 个月（本次实测 RT 到 2026-12-14）。`GET /v1/verification` 待处理验证需人工/脚本在 client 侧解决。
**区域字典**：`GET /v1/cities` → 492 条（30 省 + 461 市 + 全国；河北 11 市 code 565–575）。

### 3.3 ali-client（国际站供应商线索）

**检索**

```http
POST /v1/search/suppliers
{
  "province": "河北",
  "keyword": "machinery",
  "locationMode": "strict",
  "country": "CN",
  "pages": 5,
  "maxEnrich": 60
}
```

- keyword / province / city 至少给一个；`locationMode=strict` 时按省市过滤（默认 strict）；`includeUnknownCity` 控制城市未知的保留。
- 返回 `queryId`，`GET /v1/suppliers?queryId=...&page=N` 翻页。
- 深度：`pages` 硬上限 20；对大省可多轮翻页（注意 10s/页，尽量在夜间完成）。
- 线索即供应商列表项（`companyId/companyName/location/mainProducts/membership/joinedYears/supplierIndex` 等摘要）。

**详情**

```http
GET /v1/suppliers/{companyId}
```

- 字段：`companyName/storeUrl/location(province,city)/country/mainProducts/businessType/membership/joinedYears/supplierIndex/rating/trust/identity/profile/performance/factoryAreaText/staffText/capabilities`
- **无 USCC / 工商**：探迹匹配只能按名称 + 省/市。

**登录/风控**：`anonymous-first`（不登录可用）；`GET /v1/status` 有 `risk.state/x5secExpiresAt/cooldownUntil/captchaRequired`；`GET /v1/verification` 返回待解滑块；`POST /v1/verification/solve` 中继自动过验证。LeadPlatform 遇 `captchaRequired/cooldownUntil` 时暂停该来源，等 client 自行恢复。

**区域字典**：`GET /v1/regions` → 373 条（31 省 + 342 市），有 `code`（`CN-13` / `CN-13-1301`）、`nameZh`、`nameEn`、`aliases`；搜索参数可传中文名、英文名、拼音或 code。

**实测校正（2026-11-16）**：

- `province=河北`（**不传 keyword**）→ totalCount 739、返回 21 家（详情全部回填），是基础路径。
- `province=河北 + keyword=hardware`（`locationMode=strict`）→ 上游 totalCount 2233，但 strict 位置过滤 + 详情回填上限内大量 location unknown → **返回 0**；`Hebei/city` 变体同样不理想。
- **扩展实验（全量逼近）**：129 个地理种子（3 省 + 11 市 + 115 县）→ 1,799 家；再加**行业词 × 城市 strict 矩阵**两轮（20 + 12 行业 × 11 市 + 省行业词）→ 净增 +663 / +328，最终 **2,961 家**；增量递减，估算上限 **3.1–3.3k**。详见 [12-河北四源覆盖实测报告](12-河北四源覆盖实测报告.md)。
- 结论：Ali **没有省级全量目录**；主路径 = 地理种子 + 行业×城市 strict 矩阵；每批约 40 次查询后冷却 60s（防详情接口风控）；名称启发式线索（约占 45%）建议详情核验。

### 3.4 mic-client（中国制造网工厂线索）

**检索**

```http
GET /api/search/factories?province=Hebei&page=1&page_size=20
```

- keyword / province / city 至少给一个；`province` 用英文 `api_value`（如 `Hebei`）或中文；`city` 为**客户端过滤**（英文/中文城市名）。
- 有用过滤：`business_type=trading_company`（外贸公司）、`audited=true`、`membership_tier=diamond|gold`、`annual_revenue`、`rd_capacity`。
- 返回列表项（工厂/贸易公司摘要：`account/company_name/province/city/main_products/membership/audited/business_types`）。
- 深度策略：Mic 的上游分页受客户端控制；建议**按省检索**（城市过滤会损失召回），城市字段随结果返回后在本地按映射过滤/标注。

**详情**

```http
GET /api/companies/{account}?include=audit,contacts,reviews
```

- 字段：`company_name/province/city/address/established_at/main_products/business_types/membership/audited/capability_stars/employees/turnover/plant_area/company_url`
- `include=contacts` 可能返回公开联系方式 → **只作为来源证据保存，不作为交付联系人**（交付联系人统一以探迹解锁为准，避免未核实号码）。
- 无 USCC → 探迹按名称 + 省/市匹配。

**登录/风控**：匿名可用；client 内置 Focus Captcha 处理；`GET /api/version` 可查版本与上游契约检查时间。
**区域字典**：`GET /api/regions` → 32 省（英文 `api_value`）；`GET /api/regions?province=Hebei` → 河北省 11 市（`cities_complete=true`）。其它省 `cities_complete=false`，城市可能缺失（一期只跑河北，风险可控）。

### 3.5 tanji-client（匹配 + 工商 + 解锁）

**按 USCC 匹配（首选）**

```http
POST /v1/search/name
{"name":"91130100XXXXXXXXXX","field":"socialCreditCode","pageSize":20,"maxPages":1}
```

**按名称匹配（兜底）**

```http
POST /v1/search/name
{"name":"河北XX进出口有限公司","field":"name","pageSize":20,"maxPages":2}
```

- 响应 `SearchResult`：`queryId/companies[]/page/pageSize/total/hasMore/pagesFetched/warnings`；列表项 `CompanySummary` 含 `id/name/uscc/legalRepresentative/regCapital/foundTime/address/province/operStatus/industry/scale/phoneCount/emailCount/contactCount/unlocked/tags/score/rankScore`。
- 搜索/翻页/详情**不扣额度**。
- **英文抬头匹配（实测）**：`field=name` 传 Ali/Mic 英文名可命中中文注册主体（示例丙/示例乙/示例甲 3/3，score 224–466）；匹配结果需记录候选与置信度，避免同名/缩写误配。

**工商详情**

```http
GET /v1/companies/{id}
```

- 字段映射见第 5 节；详情缓存 7 天（`refresh=true` 可强制刷新）。

**联系人（未解锁为空）**

```http
GET /v1/companies/{id}/contacts
```

- 未解锁：`unlocked=false, contacts=[]`；解锁后：手机/固话/邮箱明文（`masked=false`），含 `name/position/department/region/source/isKeyLead`。

**解锁（消耗 1 额度点）**

```http
POST /v1/companies/{id}/unlock
{"confirm":true,"quota":true,"contacts":true,"idempotencyKey":"unlock:cmp_xxx:2026-11-16"}
```

- 响应 `UnlockResult`：`companyId/companyName/alreadyUnlocked/unlockedBy/unlockedAt/quotaCost/quotaBefore/quotaAfter/contacts`。
- `alreadyUnlocked=true` → 不扣额度（业务幂等）；`QUOTA_EXHAUSTED`（409）→ LeadPlatform 转 `waiting_quota`。
- 建议 `quota=true, contacts=true`：一次拿到精确额度与联系人（2 次附加上游调用，仍只扣 1 点）。

**额度与账号**：`GET /v1/status` → `quota.daily/monthly/enterpriseMonthly {limit,used,remaining,unit}` + `settlementDay` + `nearlySevenDayUnlockCount`；`GET /v1/accounts` 多账号列表（当前仅 `main`）。
**高级筛选（预留）**：`GET /v1/filters/registry`（工商/联系方式/招聘/资质等 12 类，含 `hasECRCreditRating`、`ecrBusinessType`、`business`、`industriesV2`、`address` 等）→ 未来「外贸属性校验」可直接升级为 `POST /v1/search/advance`，无需改数据模型。

### 6.6 fuma-platform 海关接口（v0.3）

**查询**

```http
POST /v1/customs/query
Authorization: Bearer $FUMA_API_TOKEN
content-type: application/json

{
  "accountId": "acct_01",
  "inputCompany": "Hebei Sample-A Metal Products Co., Ltd.",
  "companyFlag": 1,
  "page": 1,
  "pageSize": 20,
  "forceRefresh": false,
  "allowStale": true
}
```

- `accountId`：fuma 账号（当前 `acct_01`，账号持有人已脱敏），用于海关数据权限校验；无权限返回 `permission_denied`。
- `inputCompany`：公司关键词（≥2 字符）；**英文抬头可直接命中**（实测 Ali/Mic 3/3 有数据）。
- `companyFlag`：`1`=进口数据视图、`2`=出口数据视图；两者数据源/覆盖不同，**都要查**。
- `pageSize` 实测可到 100；LeadPlatform 默认 20（样本量足够、体积可控）。
- 响应 `data`：`list[]`（提单记录）、`totalNum/allCount`（模糊命中总数）、`exactCount`（实测恒 0，不用）、`cached/cachedAt/expiresAt/source/stale/upstreamVersion`。
- fuma 有**强制本地缓存**（同参数 24h；重复查询 `cached=true` 不请求上游），`forceRefresh=true` 可强制刷新。
- 请求走账号级请求池：**账号串行 + 限速**，LeadPlatform 必须串行调用（并发 ≤1）。

**提单记录字段（fuma `list[]` → `company_customs_profiles` 聚合）**

| fuma 字段 | 用途 |
|---|---|
| `tradeno / blnumber` | 去重键 / 样例展示 |
| `inout` | `import` / `export` |
| `rawimporter / importer / usedbuyername` | 进口商（买家）名称；名称过滤与 Top 买家 |
| `rawexporter / exporter / usedsuppliername` | 出口商（供应商）名称；名称过滤与 Top 供应商 |
| `importercountryen / destcountry` | 出口目的国 |
| `exportercountryen / origincountry` | 进口来源国 |
| `hscode` | HS 前 4 位聚合 |
| `detail` | 产品描述（Top 产品） |
| `regdate` | 日期范围 |
| `weight / count / countunit / money` | 样本重量/件数/金额（money 常为 0） |
| `departureport / dischargeport / containernumber` | 样例展示（可选） |

**名称匹配**：英文抬头归一化为 token（去 `CO/LTD/GROUP` 等），在 exporter/importer 全字段中匹配；区分「公司作为出口商」与「公司作为进口商」两类证据；中文名查询仅作补充（实测中文名 flag=2 多为 0）。详见 08 文档。

**字典/缓存**：`GET /v1/customs/dictionaries?kind=countries|hscode|sources|updatelog`（国家/HS/数据源/更新日志，TTL 7 天）；`GET /v1/customs/cache/stats`（命中率/条目/占用）。

## 7. 错误码归一（上游 → LeadPlatform）

| 上游表现 | 归一 |
|---|---|
| 401 / `UNAUTHORIZED` / `loggedIn=false` | `SOURCE_SESSION_INVALID`：跳过该来源，标记 `source_health=session_invalid`，Run 继续 |
| `verification.pending` / `captchaRequired` / `cooldownUntil` | `SOURCE_VERIFICATION_PENDING`：来源降级 + 冷却，稍后重试 |
| 429 / `RATE_LIMITED` | `UPSTREAM_RATE_LIMITED`：按 client 的 retry-after/cooldown 退避 |
| 5xx / ECONNREFUSED / 超时 | `SOURCE_UNAVAILABLE`：重试（指数退避，最多 3 次） |
| `QUOTA_EXHAUSTED`（tanji） | 解锁任务 → `waiting_quota`（不计失败） |
| `NOT_FOUND` | 数据被上游删除/查询会话过期 → 跳过并记录 |
| fuma `permission_denied` | `CUSTOMS_PERMISSION_DENIED`：标记 fuma 来源不可用，海关任务暂停（不影响主流程） |
| fuma 无数据 `totalNum=0` | 正常 `no_data`（不重试） |
| fuma 401 / 账号失效 | `SOURCE_SESSION_INVALID`：检查 fuma 账号登录态并暴露到 `/v1/sources` |
| 其它 4xx | `UPSTREAM_BAD_REQUEST`：记录请求摘要（不含 PII），任务失败重试/死信 |
