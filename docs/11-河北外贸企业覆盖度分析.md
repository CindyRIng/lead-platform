# 11 · 河北外贸企业覆盖度分析（回答 Q6）

- 日期：2026-11-16（基于真实只读实测）
- 问题：Q6 的 Ali 行业关键词集「是否足够覆盖河北所有外贸企业」？
- 结论：**不足以覆盖「全部」，且关键词不是覆盖的决定因素**。四源能覆盖的是「活跃平台可见的外贸企业」子集；要接近全量需要新增发现源（建议 Tanji 广覆盖，二期）并配套解锁优先级。

---

## 0. 实测结果（2026-11-16，详见 [12-四源覆盖实测报告](12-河北四源覆盖实测报告.md)）

- Mic **5,008**（省关键词+11 市关键词全量并集，与预期 4000+ 一致）
- Ali **2,961**（129 种子 + 两轮行业×城市扩展；无省级全量目录，接近 3 千、增量递减）
- Boss **1,188** / 智联 **1,261**（11 市 × 10 关键词第 1 页；去重后 **2,375**）
- Ali∩Mic **459**；招聘↔Ali/Mic 重叠抽样估算 **≈299**（160 样本 3.75%）
- **四源去重后合计 ≈9,586 家**（区间 9,352–9,821）

### 0.1 Ali 深度扩展实验（回答“跑到全量能有多少”）

| 阶段 | 查询 | 净增 | 累计 |
|---|---|---|---|
| 扩展种子（3 省 + 11 市 + 115 县） | 129 | 1,799 | 1,799 |
| 行业×城市矩阵 round1（6 行业） | 66 | +171 | 1,970 |
| 扩展 round1（20 行业 × 11 市 + 20 省行业词） | 240 | +663 | 2,633 |
| 扩展 round2（12 行业 × 11 市 + 12 省行业词） | 144 | +328 | **2,961** |
| 县名深翻页（试跑后停） | 45 | +31 | 收益过低 |

- 增量从 **+663 → +328** 递减；按趋势估算 Ali 可发现上限约 **3.1–3.3k**。
- Ali **无官方省级企业总数**，所以“全量”无法严格定义；2,961 是“种子+行业词”可发现量，不是平台真实全量。
- 结论：用户预期“几千家”基本达到（≈3 千）；继续扩 2–3 轮可再 +300–600，但收益递减。

## 1. 覆盖率结论（先说结果）

| 数据源 | 可覆盖范围（河北） | 实测/估算规模 | 能否「全量枚举」 |
|---|---|---|---|
| **Ali** | 河北在 Ali 有店铺的供应商 | 省检索 `totalCount≈732–739` | ⚠️ 受客户端限制：单查询 `pages≤20`（约 400 条）且 `maxEnrich` 限流；需分段查询（城市/sort/refresh）才能取完，**关键词过滤只会减少覆盖** |
| **Mic** | 河北在 Mic 有工厂/贸易公司 | `total=1101`，56 页 | ✅ 可按省全量翻页（快、有缓存） |
| **Boss** | 河北正在招「外贸相关岗位」的公司 | 石家庄单城市 8 个关键词第 1 页并集 **122 家**（单关键词 20 家 → +510%）；11 城全量远大于此 | ⚠️ 仅覆盖「正在招聘」的公司；需关键词扩展 + 全翻页 |
| **智联** | 同上（正在招聘的公司） | 未全量测；量级与 Boss 相近 | ⚠️ 同上 |
| **四源去重合计（实测估算）** | 平台可见的活跃线索 | **≈9,586 家**（9,352–9,821；见 12 文档） | 只能「尽量全」 |
| **Tanji 高级搜索（潜在第 5 源）** | 河北 + 经营范围含「进出口」/海关资质 | 实测全国「经营范围含进出口」`total=100001`（上游展示上限）；河北子集预计**数万家级** | 搜索免费、可翻页；但候选量巨大，**解锁额度远不够**，必须分级 |

> 关键事实：Boss/智联只覆盖**正在招人**的外贸公司；Ali/Mic 只覆盖**在平台开店**的供应商/工厂；大量外贸企业（尤其不招人、不做 B2B 平台的）不在四源里。因此“覆盖河北所有外贸企业”用四源无法保证，只能定义为“平台可见 + 活跃”的线索集合。

## 2. 实测证据

### 2.1 Boss 关键词扩展实验（石家庄，每词第 1 页 20 家）

| 关键词 | 返回公司 | 累计去重并集 |
|---|---|---|
| 外贸 | 20 | 20 |
| 跨境电商 | 20 | 39 |
| 外贸跟单 | 20 | 55 |
| 海外销售 | 20 | 72 |
| 国际业务 | 20 | 86 |
| 外贸专员 | 20 | 98 |
| 外贸助理 | 20 | 108 |
| 外贸主管 | 20 | **122** |

- 结论：单关键词第 1 页并集仅 20 家；8 个关键词 → 122 家（+510%）。**关键词扩展对 Boss/智联覆盖是有效的**；但即使扩展，也只覆盖“当前在招”的公司。
- 注意：每个关键词深翻页（第 2-N 页）会继续增加并集；上述仅为第 1 页实验结果，用于证明趋势。

### 2.2 Ali 全量枚举的客户端约束

- 省检索 `province=河北`：`totalCount≈732–739`，单页约 20 家。
- 实测 `pages=20, maxEnrich=40`：请求 19 页、原始 361 条，但**只返回 40 家**（`enrichLimitReached=true`）——`maxEnrich` 决定可返回的详情回填数量；要全量必须提高 `maxEnrich`（≤300）并多次查询。
- `GET /v1/suppliers?page=N` 只能取「已抓取过的页」（`PAGE_NOT_AVAILABLE`），不能事后补页 → **必须在 search 时指定足够 pages**；而 `pages≤20`（约 400 条）< 739 → 需要**分段查询**（按城市/排序/刷新）才能取完。
- 结论：Ali 覆盖靠「按省全量 + 分段枚举」，**行业关键词只会缩小结果集**；关键词适合本地打标签/二次筛选，不适合作为覆盖手段。

### 2.3 Tanji 广覆盖能力（探索性）

- `POST /v1/search/advance` 支持 `business contains 进出口`（实测可用，全国 total 显示 100001 上限）。
- 区域过滤需要 `address` tree 的正确取值（自由文本 `石家庄` 返回 0；`河北省`/`河北` 能过滤但总数仍被 100001 截断）→ **filter DSL 的省/市值需要专项 spike**，但方向可行。
- 搜索/翻页**不扣额度**，只有解锁联系人扣额度 → 理论上可把河北「经营范围含进出口」的企业全部发现并免费补全工商；但候选数万家，**解锁额度（月 1500、当前剩 223）只能覆盖极小比例** → 必须定义优先级/分批策略。

## 3. 对 Q6 的直接回答

1. **Q6 的 Ali 行业关键词集可以接受，但它不是“覆盖全部”的手段**：Ali 应改为「按省全量枚举 + 行业词仅本地过滤/补充」。
2. **Boss/智联的关键词集建议扩展**（默认从 5 个扩到 10 个）：
   - `外贸、外贸业务员、外贸经理、外贸单证员、国际贸易、跨境电商、外贸跟单、外贸专员、海外销售、国际业务`
   - Goal 内可覆盖/追加；实测单城市 8 关键词并集 +510%。
3. **四源覆盖上限是“活跃平台可见线索”（实测估算 ≈9,586 家/河北，见 12）**，不是“全部外贸企业”。
4. 要接近“全量”，唯一现实路径是**新增 Tanji 广覆盖发现源**（河北 + 经营范围/海关资质），但必须同时定义：
   - 候选优先级（有招聘 > 有店铺 > 仅工商）；
   - 解锁额度分配（只对高优先级解锁联系人，其余仅工商入库）；
   - 分批/长期跑策略（候选数万，按天/月滚动）。
5. 建议节奏：
   - **一期（v1）**：四源 + 关键词扩展 + Ali/Mic 全量枚举；明确对外口径为“活跃平台线索”；
   - **并行专项 spike（不阻塞 v1）**：验证 Tanji advance 的省市 tree 过滤真实覆盖量，评估“广覆盖发现”作为二期能力。

## 4. 覆盖度度量（写进 Run 统计）

为了以后能回答“到底覆盖多少”，一期在 Run 统计中增加：

| 指标 | 说明 |
|---|---|
| `perPlatform.leads/companiesNew` | 各源线索/新公司数 |
| `uniqueCompanies` | 本轮去重后公司数 |
| `crossSourceOverlap` | 多源共同命中的公司数（Boss∩智联、Ali∩Mic 等） |
| `coverageByCity` | 各城市新增公司分布 |
| `keywordYield` | 各关键词带来的新公司数（用于优化默认关键词集） |

> 有了这些指标，跑几轮河北后即可用真实数据校准“覆盖上限”，再决定是否引入 Tanji 广覆盖。
